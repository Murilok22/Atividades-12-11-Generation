Conversor de Temperatura

Este projeto simples em Python realiza a conversão de temperaturas da escala Celsius (°C) para as escalas Fahrenheit (°F) e Kelvin (K).
🛠️ Funções

    celcius_f(temperatura): Converte a temperatura de Celsius para Fahrenheit utilizando a fórmula:
    F=(C×1.8)+32

    celcius_k(temperatura): Converte a temperatura de Celsius para Kelvin utilizando a fórmula:
    K=C+273

🚀 Como Executar

    Execute a célula que define as funções (celcius_f e celcius_k).
    Execute a célula interativa seguinte, insira um valor numérico de temperatura em Celsius e veja os resultados impressos na tela.
